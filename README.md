# 愿笺 · 致岁念

一个静态的祝福网站：十二张愿笺、四封短笺、一本祝福特刊、一段祝词、一支签，最后盖一个印章。

不谈别的，只谈祝愿。纸、墨、朱砂，正文宋体，笺与祝词用楷体。没有外部字体、图片或统计脚本，所有纹理、远山、信封、印章、落雪都是 CSS / SVG / Canvas 画的。

## 直接打开

双击 `index.html` 即可，不需要服务器，也不需要联网。

手机或分享：用 `愿笺-致岁念.html`。样式和脚本都内联在里面的单文件版，约 95 KB，直接发文件就能打开。

## 文件说明

```
index.html              页面结构与全部文案
assets/style.css        样式
assets/main.js          交互：愿笺翻牌、短笺、校刊翻页、抽签、印章、落雪、目录
愿笺-致岁念.html         单文件版（可直接发送）
preview/                预览图，仅供查看，不参与网页
```

## 想改哪里

- **十二张愿笺**：`index.html` 里的 `.wishcard`。每张卡有正面的主题、背面的祝福，以及 `aria-label` 里的同一句话，三处一起改。
- **四封短笺**：`index.html` 里的 `.env` 部分，标题在 `.env__date`，祝福在 `.env__letter`。
- **五页特刊**：`index.html` 里的 `.jpage` 部分（封面、卷首、散文、诗、编后）。
- **祝词**：`index.html` 里 `id="blessing"` 的 `.letter__body`。
- **十二支签**：`assets/main.js` 里的 `WISHES`。最后一句固定是压轴的「祝你幸福而自在」。
- **署名、月份**：`.letter__name` 和 `.end__sign`。
- **页脚日期**：`.end__foot` 与 `.footer`。
- 改完 `index.html` / CSS / JS 后，重新生成单文件版：把 `assets/style.css` 和 `assets/main.js` 分别替换掉单文件里的 `<style>` / `<script>` 内容即可。

## 交互

- 首屏：随鼠标的墨晕、浮尘、逐字显现。
- 目录：右上角「目录」，全屏索引，支持 Esc 关闭。
- **愿笺**：点一张翻一张，可再点合上；「全部翻开」会依次翻开十二张；十二张都翻开后，出现「十二愿，都给你」。
- **短笺**：点信封拆开，再点收起；支持键盘。
- **校刊**：点书页或「下一页」，五页；封面、卷首、散文、诗、编后。
- **抽签**：点「抽一支」，十二支不重复，最后一支是「祝你幸福而自在」；抽完可再来一轮。
- **落款**：点虚线方框里的印章，盖下「岁念」，签名浮现；页尾落雪。
- 祝词末尾的「存下这封祝词」会调用浏览器打印，可另存为 PDF；打印样式只保留祝词信纸。

## 部署

任选一种：

1. **Netlify Drop**：把整个文件夹拖到 <https://app.netlify.com/drop>，几秒后得到网址。
2. **Vercel**：`vercel` 或把仓库连到 Vercel，框架选 Other，直接部署。
3. **GitHub Pages**：推到仓库，Settings → Pages，选根目录。

单文件版也可以直接上传，或作为附件发出去。

## 其他

- 适配手机与桌面；尊重系统「减少动态效果」。
- 无 JS 时正文仍然完整可读（抽签会提示需要开启 JS）。
- 如果系统里没有宋体/楷体，会回退到本机的中文衬线字体，排版不会散。
